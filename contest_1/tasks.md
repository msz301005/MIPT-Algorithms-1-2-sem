# A (1 балл). Красти рейс

| | Все языки | (make) Java 21 (Temurin JDK) | (Make) Clang 17.0.1 C++20 |
|---|---|---|---|
| Ограничение времени | 2 секунды | 2 секунды | 1 секунда |
| Ограничение памяти | 32 Мб | 128 Мб | 32 Мб |
| Ввод | стандартный ввод или input.txt | | |
| Вывод | стандартный вывод или output.txt | | |

В Бикини Боттом вот-вот начнётся великая гонка на доставку Крабсбургеров! Ресторан «Красти Краб» выбирает команду самых быстрых доставщиков. В конкурсе участвует N кандидатов-улиток, скорость каждого доставчика (в бульвалях в минуту) записана в массиве $a_i$.

Однако Перл придумала забавное правило: команду можно собрать так — взять всех доставщиков с номерами от 1 до $l$, а затем от $r$ до $N$ (то есть двух несмежных отрезков: сначала от начала до $l$, потом от $r$ до конца). Самая медленная улитка определяет скорость всей команды!

Патрик интересуется: «А что если выбрать вот такие команды?» — и задаёт $Q$ вопросов. В каждом вопросе он задаёт два числа $l_i$ и $r_i$ $(1 \le l_i \le r_i \le N)$ и спрашивает: «А какая будет минимальная скорость в команде, если выбрать всех от 1 до $l_i$, и от $r_i$ до N?»

## Формат ввода

В первой строке $N$ $(1 \le N \le 10^5)$ — количество кандидатов.

Во второй строке $N$ чисел $a_i$ $(-10^9 \le a_i \le 10^9)$ — скорость доставки бургера каждым кандидатом (отрицательная скорость это не баг, а фича).

Далее число $Q$ $(1 \le Q \le 10^6)$ — количество вопросов Патрика.

Далее $Q$ строк, в каждой по два числа $l_i$ и $r_i$ — параметры выбора команды.

## Формат вывода

Выведите $Q$ строк — ответы на запросы.

## Пример

**Ввод**
```
5
5 1 4 2 3
6
1 5
1 4
2 4
3 3
3 5
1 3
```

**Вывод**
```
3
2
1
1
1
2
1
```

# B (3 балла, с ревью). Вкус салата

В Бикини Боттом объявлен новый конкурс на лучший салат из водорослей! Все водоросли, собранные со дна океана, Спанч Боб аккуратно расположил в единый ряд прямо на прилавке перед рестораном «Красти Краб». Спанч Боб пронумеровал растения от 1 до N, чтобы было проще анализировать отзывы покупателей.

У каждой водоросли есть показатель питательности $a_i$. Спанч Боб мечтает узнать, какие комбинации соседних водорослей окажутся самыми питательными для нового фирменного салата. Для этого он предлагает термин: вкус салата определяется средним геометрическим питательности выбранных подряд идущих водорослей.

Напомним, что среднее геометрическое вычисляется по формуле:

$$\sqrt[r-l+1]{a_l \cdot a_{l+1} \cdot \ldots \cdot a_r}$$

## Формат ввода

В первой строке дано число $N$ $(1 \le N < 3 \cdot 10^5)$ — количество сортов водорослей. На второй строке $N$ вещественных чисел $a_i$ $(0.01 \le a_i \le 10^2)$ с двумя знаками после десятичной точки — питательность i-го сорта.

На третьей строке дано единственное число $Q$ $(1 \le Q \le 10^5)$ — количество запросов подсчёта вкуса салата на подтвердке.

Далее $Q$ строк запросов в формате $i\, j\ (0 \le i \le j \le N-1)$, i, j — индексы массивов, задающие отрезок для запроса.

## Формат вывода

Для каждого запроса на новой строке выведите полученную питательность салата с точностью до не менее шестого знака после запятой.

# C (2 балла). Очередная суматоха в Отделе Тайн

| Язык | Ограничение времени | Ограничение памяти | Ввод | Вывод |
|---|---|---|---|---|
| Все языки | 3 секунды | 256Mb | стандартный ввод или input.txt | стандартный вывод или output.txt |
| Java 17 (Temurin JDK) | 10 секунд | 256Mb | | |
| Go 1.23.0 | 5 секунд | 256Mb | | |
| Java 20 (Temurin JDK) | 10 секунд | 256Mb | | |
| (make) GCC C++17 | 3 секунды | 256Mb | | |
| (Make) Clang 17.0.1 C++20 | 3 секунды | 256Mb | | |

Отдел Тайн Министерства магии состоит из двух стеллажей A и B. Известно, что пророчества на каждой полке отсортированы по порядку времени, когда они были созданы. В стеллаже A n полок, а в B — m полок. При этом в обоих стеллажах все полки вмещают по l пророчеств.

Тому, кого нельзя называть, известно, что все пророчества в отделе тайн хранятся в виде двух частей: одна в стеллаже A, другая — в B. Также он знает, что половины пророчеств на полках $A_i$ и $B_j$ половины пророчеств соответствуют друг другу, если найти такое $k$, что $\max(A_{ik}, B_{jk})$ минимален. Тогда такое $A_{ik}, B_{jk}$ и будут нужными пророчествами. Если таких $k$ несколько, то подойдёт любое.

Так как Тому Реддлу осталось недолго, он просит вас искать такие $k$ на его запросы вида $(i, j)$.

## Формат ввода

На первой строке числа $n, m, l\ (1 \le n, m \le 900;\ 1 \le l \le 3\,000)$. Следующие $n$ строк содержат описания полок $A_i$. Каждая полка описывается перечислением $l$ элементов. Время записи пророчеств — целые числа от 0 до $10^9-1$. Далее $m$ строк с описанием массивов $B_j$ в таком же формате.

Полки и элементы внутри массива нумеруются с 1.

На следующей строке число запросов Тома Реддла $q\ (1 \le q \le n \cdot m)$. Следующие $q$ строк содержат пары чисел $i, j\ (1 \le i \le n,\ 1 \le j \le m)$.

## Формат вывода

Выведите $q$ чисел от 1 до $l$ — ответы на запросы.

## Пример

**Ввод**
```
4 3 5
1 2 3 4 5
1 1 1 1 1
0 99999 99999 99999 99999
0 0 0 0 99999
5 4 3 2 1
99999 99999 99999 0 0
99999 99999 0 0 0
12
1 1
1 2
1 3
2 1
2 2
3 1
3 2
4 1
4 2
4 3
```

**Вывод**
```
3
4
3
5
1
2
2
4
4
3
```

# D (2 балла). Люминесцентные кораллы

| | Все языки | (make) Java 21 (Temurin JDK) | (Make) Clang 17.0.1 C++20 |
|---|---|---|---|
| Ограничение времени | 2 секунды | 2 секунды | 1 секунда |
| Ограничение памяти | 64 Мб | 64 Мб | 16 Мб |
| Ввод | стандартный ввод или input.txt | | |
| Вывод | стандартный вывод или output.txt | | |

Губка Боб и Патрик попали в ловушку от планктона в Бикини Боттом! Чтобы выбраться, им нужно осветить все N люминесцентных кораллов, стоящих в ряд. Для этого у них есть k супер-фонарей от Сэнди, который может осветить подряд отрезок длины $ell$. Но есть одна загвоздка: по правилам Красти Краба, одновременно могут быть включены не более k фонарей.

Какова минимальная длина освещаемого фонарём отрезка $ell$, чтобы команда могла осветить все кораллы и выбраться?

## Формат ввода

На первой строке $n\ (1 \le n \le 10^5)$ и $k\ (1 \le k \le n)$.

На второй строке $n$ чисел $x_i\ (|x_i| \le 10^9)$ — координаты кораллов.

## Формат вывода

Минимальное такое $\ell$, что кораллы можно осветить $k$ отрезками длины $\ell$.

## Пример

**Ввод**
```
6 2
1 2 3 9 8 7
```

**Вывод**
```
2
```
