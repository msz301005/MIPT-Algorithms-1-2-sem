# A. ПСП (1 балл)

| | Все языки | (make) Java 21 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1 секунда | 2 секунды |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

Рассмотрим строки, состоящие только из символов `(`, `)`, `[`, `]`, `{`, `}`.

Строка *S* называется правильной скобочной последовательностью, если она получена по одному из следующих правил:

- *S* = ε (то есть *S* — пустая строка);
- *S* = *AB*, то есть *S* равна конкатенации *A* и *B*, где *A* и *B* — правильные скобочные последовательности;
- *S* = (*A*) или *S* = [*A*] или *S* = {*A*}, где *A* — правильная скобочная последовательность.

По данной скобочной последовательности *S* определите, является ли она правильной.

## Формат ввода

Единственная строка содержит последовательность *S* (1 ≤ |*S*| ≤ 10^5).

## Формат вывода

Выведите YES, если *S* является правильной скобочной последовательностью, и NO иначе.

## Пример 1

**Ввод**
```
()[]
```

**Вывод**
```
YES
```

## Пример 2

**Ввод**
```
([)]
```

**Вывод**
```
NO
```

**Ввод**

В этой задаче можно пользоваться встроенными структурами данных, необязательно реализовывать всё вручную.

Вам нужно реализовать структуру данных, которая поддерживает очередь элементов и обрабатывает запросы следующих типов:

- `+ x`: добавить число *x* в конец очереди;
- `* x`: вставить число *x* **в середину** очереди (если в очереди нечётное число элементов, то *x* встаёт сразу за центральным элементом);

Первая строка содержит одно число *n* (1 ≤ *n* ≤ 10^5) — количество запросов к структуре.

В следующих *n* строках содержатся запросы в описанном выше формате. Элементы, вставляемые в очередь, — целые числа в диапазоне [1, *n*].

## Формат вывода

Для каждого запроса типа «-» выведите число, извлечённое из очереди.

## Пример 1

**Ввод**
```
7
+ 1
+ 2
-
-
+ 3
+ 4
-
```

**Вывод**
```
1
2
3
```

## Пример 2

**Ввод**
```
10
+ 1
+ 2
* 3
-
-
+ 4
* 5
-
-
-
```

**Вывод**
```

3
2
```

# D. Минимум в очереди (2 балла, с ревью)

| | Все языки | (make) Java 21 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1 секунда | 3 секунды |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

В этой задаче вам предстоит реализовать очередь с поддержкой минимума. Формально, разработайте структуру данных, которая поддерживает очередь элементов и обрабатывает запросы следующих типов:

- `enqueue x`: добавить число *x* в конец очереди. В ответ на этот запрос выведите «ok».
- `dequeue`: удалить из очереди начальный элемент. В ответ на этот запрос выведите значение удалённого элемента или «error», если очередь была пуста.
- `front`: вывести элемент из начала очереди.
- `size`: вывести число элементов в очереди.
- `clear`: очистить очередь, удалив из неё все элементы. В ответ на этот запрос выведите «ok».
- `min`: вывести значение минимального элемента в очереди. Если очередь была пуста, выведите «error».

## Формат ввода

Первая строка содержит одно целое число *n* (1 ≤ *n* ≤ 2·10^5) — число запросов к структуре.

В следующих *n* строках содержатся запросы в описанном выше формате. Добавляемые в очередь элементы — целые числа в диапазоне [1, 10^9].

## Формат вывода

Для каждого запроса выведите ответ на него.

## Пример

**Ввод**
```
9
enqueue 2
front
dequeue
size
dequeue
size
enqueue 1
enqueue 2
size
min
```

**Вывод**
```
ok
2
2
0
error
ok
ok
2
1
```

# F. Бинарная куча (2 балла, с ревью)

| | Все языки | (make) Java 21 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1 секунда | 3 секунды |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

В этой задаче вам предстоит реализовать бинарную кучу. Не используйте библиотечные функции, реализуйте все методы самостоятельно. Обработайте запросы следующих видов:

- `insert x`: вставить целое число *x* в кучу;
- `getMin`: вывести значение минимального элемента в куче (гарантируется, что к этому моменту куча не пуста);
- `extractMin`: удалить минимальный элемент из кучи, выводить его не нужно (гарантируется, что к этому моменту куча не пуста);
- `decreaseKey i Δ`: уменьшить число, вставленное на *i*-й запрос, на целое число Δ ≥ 0 (гарантируется, что *i*-й запрос был осуществлён ранее, являлся запросом добавления, а добавленное на этом шаге число всё ещё лежит в куче!). Обратите внимание, число *i* равно номеру запроса среди всех запросов, а не только среди запросов добавления!

## Формат ввода

В первой строке содержится число *q* (1 ≤ *q* ≤ 10^6), означающее число запросов.

В следующих *q* строках содержатся запросы в описанном выше формате. Добавляемые числа *x* и поправки Δ лежат в промежутке [-10^9, 10^9], а Δ ≥ 0.

## Формат вывода

На каждый запрос вида `getMin` выведите ответ в отдельной строке.

## Пример 1

**Ввод**
```
5
insert 5
decreaseKey 1 3
getMin
insert 1
getMin
```

**Вывод**
```
2
1
```

## Пример 2

**Ввод**
```
5
insert 5
getMin
extractMin
insert 10
getMin
```

**Вывод**
```
5
10
```

# G. Первые элементы последовательности (1 балл)

| | Все языки | (make) Java 21 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1.5 секунд | 3 секунды |
| Ограничение памяти | 8Mb | 32Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

Дана длинная последовательность целых чисел длины *n*. Требуется вывести в отсортированном виде её наименьшие *k* элементов.

Чтобы не пришлось считывать большую последовательность, её элементы задаются формулой. А именно, во входных данных содержится *a_0*, *x*, *y*. Тогда *a_i* = (*x* · *a_{i-1}* + *y*) mod 2^30. Нужная последовательность есть *a_1*, *a_2*, ..., *a_n*.

## Формат ввода

Первая строка содержит два целых числа *n* и *k* (1 ≤ *n* ≤ 10^7, 1 ≤ *k* ≤ 1000).

Вторая строка содержит три целых числа *a_0*, *x*, *y* (0 ≤ *a_0*, *x*, *y* < 2^30).

## Формат вывода

Выведите *k* наименьших элементов последовательности в отсортированном виде.

## Пример

**Ввод**
```
3 2
3 1 2
```

**Вывод**
```
5 7
```

## Примечания

В первом тестовом примере *a* = [5, 7, 9].

# M. Игра на цикле (4 балла)

| | Все языки | (make) Java 21 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1 секунда | 3 секунды |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

По кругу расставлены положительные числа *a_1*, *a_2*, ..., *a_n*. Два игрока играют в игру. Ходы игроков чередуются. На каждом ходу игрок выбирает одно из ещё никем не выбранных чисел и добавляет его к своему счёту.

На первом ходе первый игрок, а на втором ходе второй игрок могут выбрать любые числа. Но на следующих ходах каждый игрок может выбирать только число, которое является соседним в круге для одного из уже выбранных им чисел.

Каждый игрок стремится максимизировать свой итоговый счёт. Выведите результат игры, если оба игрока играют оптимально.

## Формат ввода

Первая строка содержит одно целое число *n* (3 ≤ *n* ≤ 10^6).

Вторая строка содержит *n* целых чисел *a_1*, *a_2*, ..., *a_n* (1 ≤ *a_i* ≤ 10^9).

## Формат вывода

Выведите два целых числа: счёт первого игрока и счёт второго игрока.

## Пример

**Ввод**
```
4
1 2 3 4
```

**Вывод**
```
5 5
```
