Тут нет легенды, чистая классика.

Вам требуется написать программу, которая по заданной последовательности находит максимальную невозрастающую её подпоследовательность (то есть такую последовательность чисел $a_{i_1}, a_{i_2}, \dots, a_{i_k}$ ($i_1 < i_2 < \dots < i_k$), что $a_{i_1} \ge a_{i_2} \ge \dots \ge a_{i_k}$ и не существует последовательности с теми же свойствами длиной $k+1$).

## Формат ввода

В первой строке задано число $n$ — количество элементов последовательности ($1 \le n \le 239017$). В последующих строках идут сами числа последовательности $a_i$, отделённые друг от друга произвольным количеством пробелов и переводов строки (все числа не превосходят по модулю $2^{31} - 2$).

## Формат вывода

Вам необходимо выдать в первой строке выходного файла число $k$ — длину максимальной невозрастающей подпоследовательности. В последующих строках должны быть выведены (по одному числу в каждой строке) все номера элементов исходной последовательности $i_j$, образующих искомую подпоследовательность. Номера выводятся в порядке возрастания. Если оптимальных решений несколько, разрешается выводить любое.

## Пример

**Ввод**
```
5
5 8
10 4 1
```

**Вывод**
```
3
1 4 5
```

Вдоль прямой дороги расположены дома. Дорога представляется целочисленной осью, а расположение каждого дома задаётся одним целым числом — координатой на этой оси. Никакие два дома не имеют одинаковых координат. Расстояние между двумя домами вычисляется как модуль разности их координат.

В некоторых, не обязательно во всех, домах будут построены точки влияния банды. Дом и расположенная в ней база банды имеют одинаковые координаты. Точки влияния необходимо расположить в домах таким образом, чтобы общая сумма расстояний от каждого дома до ближайшего к ней точки была минимальной.

# C. Миссия с самолетиком (3 балла, с ревью)

| | Все языки | (make) Java 17 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1 секунда | 2 секунды |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

Надеюсь, вы все проходили миссию с самолетиком в GTA SA. Так или иначе, она считается одной из труднейших. Вам предстоит узнать, падение с какой высоты самолетик переживет. Известно, что если его уронить с высоты не меньшей (больше или равной) ($\ge$) $x$ ($x$ — целое число от 1 до $n$) метров, то он разобьётся, что вызовет перезапуск миссии и ощущение всемирной несправедливости у играющего.

Задача осложняется тем, что вам предоставлено всего $k$ образцов самолетика. Каждый самолетик можно бросать сколько угодно раз, пока он не сломается; после этого использовать его для экспериментов больше не удастся.

Вы решили действовать так, чтобы минимизировать максимально возможное количество экспериментов, которое может потребоваться в худшем случае, чтобы это произвести. Чему равно это количество?

## Формат ввода

В первой строке входного файла записаны через пробел два целых числа $n$ и $k$ — максимальная высота для эксперимента и количество предоставленных самолетиков ($1 \le n \le 100000$, $0 \le k < n$).

## Формат вывода

В выходной файл выведите единственное число — минимальное количество экспериментов, которое потребуется совершить, чтобы узнать число $x$ и использовать не более $k$ самолетиков. Если решить задачу невозможно, выведите вместо этого $-1$.

## Пример 1

**Ввод**
```
4 2
```

**Вывод**
```
2
```

## Пример 2

**Ввод**
```
4 1
```

**Вывод**
```
3
```

## Примечания

В первом примере сначала следует уронить самолётик со второго этажа. Если он сломается, то второй бросок следует сделать с первого этажа. В случае поломки станет известно, что $x = 1$. Иначе мы узнаем, что $x = 2$.

Если же при броске со второго этажа он не сломался, бросим его с третьего этажа. При поломке будет ясно, что $x = 3$. Иначе из условия $1 \le x \le 4$ следует, что $x = 4$.

Всего будет сделано два эксперимента. В любом случае будет использовано не более чем два самолётика.

Во втором примере следует сначала уронить единственный данный нам самолётик с первого этажа, если он не сломается, то со второго, а если опять не сломался, то с третьего. При первой же поломке мы узнаем точное значение $x$. Если после трёх бросков самолётик так и не сломался, то $x = 4$.

Бой называется неинтересным, если его результат предопределён. Множество натуральных чисел называется мирным, если бой любой пары различных чисел из этого множества неинтересен. Силой множества называется сумма чисел в нём. Сколько существует мирных множеств натуральных чисел силы $n$?

## Формат вывода

Каждый район города захвачен какой-то группировкой. При этом районы пронумерованы, то есть при захвате района с каким-то номером нельзя захватывать районы с меньшими номерами. При этом Гроув-стрит после каждого захвата вынуждена отдыхать, поэтому они выработали тактику. Если $a_1, \dots, a_n$ — число гангстеров в соответствующем районе, то они могут его захватить с учетом тактики и правил выше, если выполнено одно из двух соотношений: $a_1 < a_2 > a_3 < a_4 > \dots$ или $a_1 > a_2 < a_3 > a_4 < \dots$.

Найдите наибольшее число районов, что Гроув-стрит сможет захватить с учетом тактики и правил выше.

## Формат ввода

В первой строке входного потока записано число $N$ — количество районов в Лос-Сантосе. Во второй строке записаны $N$ ($1 \le N \le 2000$) целых чисел $a_1, a_2, a_3, \dots, a_N$ ($|a_i| \le 10^9$) — число гангстеров в $i$-м районе.

## Формат вывода

```
6
1 4 2 8 6 7
```

## Пример 2

**Ввод**
```
5
1 2 3 4 5
```

**Вывод**
```

```

## Пример 3

# L. Охлаждение перевода (2 балла)

| | Все языки | (make) Java 17 (Temurin JDK) |
|---|---|---|

Некоторые переводы GTA SA были достаточно оригинальными. У вас есть NLP-модель, которая может переводить тексты из перевода GTA SA на русский. Однако для её обучения необходима выборка данных, где какие-то из переводов должны быть правильными, а какие-то — нет. Каждый алгоритм описывается двумя числами:

- $k_i$ — общее количество примеров, которые генерирует данный алгоритм
- $v_i$ — количество правильных примеров, которые генерирует данный алгоритм

При этом некоторые алгоритмы имеют одну структуру и их множества примеров вкладываются друг в друга. Из таких групп нужно взять всего один алгоритм.

Разрешено взять не больше $K$ примеров для модели, иначе обучение модели будет слишком долгим. И при этом вы хотите максимизировать итоговую сумму $v_i$, чтобы модель видела как можно больше правдоподобных примеров.

Решите данную задачу, и вы охладите серверы, затраченные Popstar, на обучение модели.

## Формат ввода

Первая строка входного файла содержит три натуральных числа $n$, $G$ и $K$ — количество алгоритмов, количество групп алгоритмов и максимальное количество примеров соответственно ($1 \le G \le n \le 300$, $1 \le K \le 10000$).

Следующие $n$ строк содержат описание алгоритмов, по одному на строке.

Метод номер $i$ описывается тремя натуральными числами $k_i, v_i, g_i$ — общее количество примеров, количество правильных примеров и номер группы соответственно ($1 \le v_i \le k_i \le 10000, 1 \le g_i \le G$).

## Формат вывода

Выведите одно число — максимальное количество правильных примеров, которое можно набрать.

## Пример

**Ввод**
```
3 3 8
3 2 1
4 2 2
5 3 3
```

**Вывод**
```
5
```

Путешественник запланировал поездку в Клетчатое Царство. Клетчатое Царство представляет из себя декартову плоскость с целочисленными координатами. Перемещение по клетчатому царству строго регламентировано: из любой клетки можно пойти либо в клетку вниз $(x, y-1)$, либо вниз-направо $(x+1, y-1)$. Путешественник может попасть в Клетчатое Царство через $n$ различных аэропортов. Координаты $i$-го аэропорта $(x_i, y_i)$. В каждый из аэропортов можно попасть $k_i$ различными рейсами. Путешественник хочет посетить $q$ главных достопримечательностей царства — «Великие Диагонали». Это прямые вида $y = x + c_j$. Путешественника интересует количество способов добраться до каждой из прямых. Способы считаются различными, если различно хотя бы что-то из списка.

1. Аэропорт
2. Рейс до аэропорта.
3. Любая клетка на пути до диагонали.
4. Клетка диагонали.

Помогите путешественнику!

Обратите внимание на примечание к первому примеру для лучшего понимания условия.

## Формат ввода

В первой строке даны числа $n, q$ ($1 \le n, q \le 300$). В $i$-й из следующих $n$ строк написаны координаты $i$-го аэропорта $(x_i, y_i)$ и количество рейсов до него $k_i$ ($-10^{18} \le x_i, y_i \le 10^{18}, 1 \le k_i \le 10^{18}$). В $j$-й из следующих $q$ строк написан коэффициент $c_j$ ($-10^{18} \le c_j \le 10^{18}$) для соответствующей прямой.

## Формат вывода

Для каждой прямой на новой строке выведите количество способов добраться до неё по модулю $10^9 + 9$.

## Пример 1

**Ввод**
```
2 2
1 5 3
3 5 5
2
0
```

**Вывод**
```
11
25
```

## Пример 2

**Ввод**
```
2 2
3 8 2
7 8 3
2
-4
```

**Вывод**
```
6
134
```

# P. Оборона города (4 балла, с ревью)

| | Все языки | (make) Java 17 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 3 секунды | 10 секунд |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

В последних миссиях Балласы воспользовались неразберихой в Лос-Сантосе. Сиджей готовится к обороне своего города. Его город представляет собой клетчатый прямоугольник размера $n \times m$, в котором каждая клетка — отдельный район. Балласы могут либо атаковать район, либо пощадить его. При этом есть районы, в которых достаточно оборонительных сооружений до следующего конца света, и Балласы не в силах их захватить, а есть те, в которых никакой защиты нет, и им в любом случае придётся капитулировать.

Балласы всё ещё справедливы, а это значит, что в любом квадрате размера $2 \times 2$ должно быть поровну до зубов защищенных и безоружных районов. Теперь Балласы хотят узнать количество различных вариантов распределения районов города на безоружные и излишне защищенные.

## Формат ввода

В первой строке входного файла задано два целых числа $n$ и $m$ ($1 \le n \le 15$ и $1 \le m \le 100$) — размер города. Далее следует $n$ строк по $m$ символов в каждой, где символ '+' означает, что соответствующий район не может быть захвачен, символ '-' — соответствующий район будет захвачен в любом случае и символ '.' — Балласы могут решить, что им делать с этим районом.

## Формат вывода

Выведите количество различных вариантов напасть на город по модулю $10^9 + 7$.

## Пример

**Ввод**
```
3 2
+.
..
.-
```

**Вывод**
```
2
```

# T. Прогулка по городу (2 балла)

| | Все языки | (make) Java 17 (Temurin JDK) |
|---|---|---|
| Ограничение времени | 1 секунда | 2 секунды |
| Ограничение памяти | 256Mb | 512Mb |
| Ввод | стандартный ввод или input.txt | |
| Вывод | стандартный вывод или output.txt | |

Карл любит гулять по своему городу, но знает, что шпионы из Балласов могут быть где угодно, поэтому он хочет узнать, по скольким различным путям он может пройти по городу. Город состоит из всех точек $(x, y)$ на плоскости таких, что $x$ и $y$ неотрицательны. Карл должен начать прогулку в начале координат (точке $(0, 0)$) и должен закончить путь в точке $(k, 0)$. Если Карл сейчас находится в точке $(x, y)$, то за один шаг он может перейти в точку $(x+1, y+1)$, $(x+1, y)$ или $(x+1, y-1)$.

Кроме того, существуют $n$ горизонтальных отрезков, $i$-й из которых идёт от точки $x = a_i$ до $x = b_i$, включительно и располагается в $y = c_i$. Гарантируется, что $a_1 = 0, a_n \le b_n \le k$, и $a_i = b_{i-1}$ для всех $2 \le i \le n$. $i$-й из этих отрезков заставляет Карла находиться только в точках с $y$ координатой в отрезке $0 \le y \le c_i$, когда его $x$ координата находится в отрезке $a_i \le x < b_i$. Заметьте, что когда один отрезок кончается, а другой начинается, то он должен находиться под обоими отрезками одновременно.

Карл хочет узнать, сколько существует различных путей (последовательностей шагов) из начала координат в точку $(k, 0)$, удовлетворяющих этим ограничениям, по модулю $10^9 + 7$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $k$ ($1 \le n \le 100, 1 \le k \le 10^{18}$) — число отрезков и $x$ координата точки назначения.

Следующие $n$ строк содержат по три целых числа $a_i, b_i$ и $c_i$ ($0 \le a_i < b_i \le 10^{18}, 0 \le c_i \le 16$) — левый и правый концы отрезка, и его $y$ координата.

Гарантируется, что $a_1 = 0, a_n \le b_n \le k$, и $a_i = b_{i-1}$ для всех $2 \le i \le n$.

## Формат вывода

Выведите число путей, удовлетворяющих ограничениям, по модулю $10^9 + 7$.

## Пример 1

**Ввод**
```
1 3
0 3 3
```

**Вывод**
```
4
```

## Пример 2

**Ввод**
```
2 6
0 3 0
3 10 2
```

**Вывод**
```
4
```
